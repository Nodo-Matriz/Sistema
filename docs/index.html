Nodo Matriz sistema de gestión

Sistema interno del Nodo Matriz

Espacio web donde habitan los formularios de gestión de cada edición: stock de proveedurías, pedidos de consumidores y las herramientas del equipo para el galpón.

Este sitio no está pensado para navegación general. Cada formulario se accede a través del link específico que se comparte en cada momento del ciclo de la edición.

Para productores

Carga de productos

Cada lunes recibís por WhatsApp un link personalizado a tu form de carga de productos. El link tiene tu identificador (id_productor) ya incluido, así no tenés que escribirlo.

Ver vista previa del form

Para consumidores

Pedido quincenal

Cada quincena se publica el formulario de pedidos con los productos disponibles en esa edición. Lo recibís por WhatsApp y se cierra en la fecha indicada.

El form de pedidos se genera nuevo cada edición, con URL del tipo: forms/pedidos-ED2026-09.html

Para el equipo del galpón

Recepción, fraccionamiento, ajustes y entrega

La app de trabajo del día de galpón, en cuatro solapas: registrar la recepción de cada productor, tildar el fraccionamiento, repartir los ajustes por faltantes y marcar la entrega de cada pedido. Todas las acciones piden la clave compartida del equipo.

Abrir la app del galpón

Carga de productos por productor

Muestra quién ya actualizó sus productos para la edición y quién falta. Desde ahí se puede abrir el form de cualquier productor para cargarlo en su nombre, o mandarle el recordatorio por WhatsApp.

Abrir carga de productos

Generar edición y comandas

Herramienta para abrir una edición nueva: genera el formulario público de pedidos con los productos y el orden de categorías elegido, y después del cierre genera las comandas por productor. También pide la clave del equipo.
